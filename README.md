# Python Security Log Analyzer (SIEM Lite)

أداة برمجية مصغرة مبنية بلغة **Python** مخصصة لتحليل ملفات سجلات الخوادم (Server Logs) ورصد محاولات الاختراق وتخمين كلمات المرور (Brute Force Attacks) بناءً على رموز الاستجابة (Status Codes).

## 🚀 مميزات المشروع:
- **تحليل السجلات (Log Parsing):** استخدام التعابير النمطية (RegEx) لاستخراج البيانات الأساسية من السجل (عنوان الـ IP، الوقت، نوع الطلب، وحالة الاستجابة).
- **كشف التهديدات الأمنية (Threat Detection):** رصد وتنبيه المُدير عند تجاوز أي عنوان IP حد معين من محاولات الدخول الفاشلة (401 أو 403).
- **سهولة التشغيل:** يعمل بالكامل بلغة بايثون دون الحاجة لتثبيت مكتبات خارجية معقدة.

## 🛠️ كيفية التشغيل في VS Code:
1. تأكد من تثبيت بايثون على جهازك (`Python 3.x`).
2. افتح مجلد المشروع داخل **VS Code**.
3. أنشئ ملفاً جديداً باسم `analyzer.py` والصق الكود بداخله.
4. افتح الطرفية (Terminal) في **VS Code** ونفذ الأمر التالي:
   ```bash
   python analyzer.py
